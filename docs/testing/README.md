- `test-cases/phase-N-test-cases.md` lists each phase's test cases: ID, steps, expected result and the automated
  test that checks it.
- On the development PC, the test cases are copied to `D:\Development\XploVoice\Test Cases`. Each run's results
  are saved to `D:\Development\XploVoice\Test Results` as `phase-N-test-results-YYYY-MM-DD.md`, with one row per
  test case ID: Pass, Fail or Not run, plus evidence.
