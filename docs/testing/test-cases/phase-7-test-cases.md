**Xplosys** · Copyright © 2026 Xplosys. All rights reserved. · Confidential – Proprietary to Xplosys

Synthetic data only. No PHI. No real payment is made: the test payment provider (development only) stands in for a gateway, and plans, prices, tax and FX rates are demo values entered for the test. Each automated case names the pytest test that checks it (`apps/api/tests`); manual cases are run in the browser.
